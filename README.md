# SkyWings - Сайт продажи авиабилетов

Лабораторная работа №2 по веб-программированию  
Тема: Верстка сайта по макету. Адаптивная верстка  
Вариант: 7 - Продажа авиабилетов

## 📋 Описание проекта

SkyWings - современный веб-сайт для бронирования и продажи авиабилетов онлайн. Проект создан с использованием HTML5, CSS3 и JavaScript, включает адаптивную верстку и множество интерактивных элементов.

## 🎯 Цели лабораторной работы

- Получение навыков переноса графического макета в HTML-разметку
- Изучение возможностей CSS и нововведений CSS3
- Получение навыков разработки веб-страниц под различные размеры экрана и различные устройства отображения
- Закрепить навык позиционирования и стилизации элементов страницы

## 🚀 Реализованный функционал

### HTML5 возможности

- Семантические теги (header, nav, section, footer, article)
- Формы с валидацией (type="email", type="tel", type="date", required)
- Meta-теги для SEO оптимизации
- Адаптивная мета-информация (viewport)

### CSS3 эффекты

#### Трансформации (CSS3 Transform)
- `transform: translateY()` - вертикальное перемещение карточек при hover
- `transform: scale()` - увеличение элементов
- `transform: rotate()` - вращение иконок и элементов
- Комбинированные трансформации: `translateY(-10px) scale(1.02)`

#### Переходы (CSS3 Transitions)
- Плавные переходы цветов и размеров (0.3s ease)
- Hover-эффекты на кнопках и карточках
- Анимация подчеркивания ссылок
- Transitions для форм при фокусе

#### Анимации (CSS3 Animations)
- `@keyframes fadeIn` - появление элементов
- `@keyframes slideInDown` - спуск заголовков
- `@keyframes slideInUp` - подъем текста
- `@keyframes bounceIn` - отскок формы поиска
- `@keyframes pulse` - пульсация элементов
- `@keyframes float` - плавающие иконки

#### Градиенты
- `linear-gradient()` для фонов
- Многоцветные градиенты
- Градиенты под разными углами

#### Тени
- `box-shadow` для карточек и элементов
- Динамические тени при hover
- Многослойные тени

#### Прочие CSS3 эффекты
- `border-radius` для скругления углов
- `backdrop-filter: blur()` для эффекта размытия
- Grid Layout для сеток
- Flexbox для гибких контейнеров
- CSS переменные (через linear-gradient)
- Псевдоэлементы `::before` и `::after`

### JavaScript функционал

- Валидация форм
- Мобильное меню (бургер-меню)
- Плавная прокрутка
- Intersection Observer для анимации при скролле
- LocalStorage для сохранения данных формы
- Динамическое изменение header при прокрутке
- Маска ввода для телефона
- Аккордеон для FAQ
- Фильтрация заказов

### Адаптивная верстка

#### Блочная и табличная модели
- Block-модель для основных секций
- Inline-block для элементов навигации
- Flexbox для гибких контейнеров
- CSS Grid для сложных раскладок

#### Медиа-запросы
```css
@media (max-width: 768px) - мобильные устройства
@media (max-width: 968px) - планшеты
@media (prefers-reduced-motion) - учет предпочтений пользователя
```

#### Адаптивные элементы
- Адаптивная навигация (бургер-меню)
- Гибкие сетки (Grid/Flexbox)
- Адаптивная типографика
- Responsive изображения

### Позиционирование элементов

- `position: sticky` - липкий header
- `position: relative/absolute` - позиционирование элементов
- `position: fixed` - мобильное меню
- Flexbox для выравнивания
- Grid для сложных раскладок

## 🚀 Запуск проекта

1. Скачайте все файлы проекта
2. Откройте `index.html` в браузере
3. Или используйте локальный сервер:
   ```bash
   # Если установлен Python
   python -m http.server 8000
   ```
4. Откройте в браузере: `http://localhost:8000`
