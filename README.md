**Тема:** Верстка сайта по макету. Адаптивная верстка

## Описание проекта

SkyWings - современный веб-сайт для бронирования и продажи авиабилетов онлайн. Проект создан с использованием HTML5, CSS3 и JavaScript, включает адаптивную верстку и множество интерактивных элементов.

## Цель работы

Получение навыков переноса графического макета в HTML-разметку. Изучение возможностей CSS и нововведений CSS3. Получение навыков разработки веб-страниц под различные размеры экрана и различные устройства отображения. Закрепление навыков позиционирования и стилизации элементов страницы.

## Использованные технологии

### HTML5 возможности

- **Семантические теги** - header, nav, section, footer, article
- **Формы с валидацией** - type="email", type="tel", type="date", required
- **Meta-теги для SEO** - description, keywords, viewport
- **Доступность** - ARIA-атрибуты, правильная структура заголовков

### CSS3 возможности

**Трансформации (Transform):**
- **translateY()** - вертикальное перемещение карточек при hover
- **translateX()** - горизонтальное движение элементов
- **scale()** - увеличение элементов (кнопки, карточки, иконки)
- **rotate()** - вращение иконок (360deg при hover)

**Комбинированные трансформации:**
```css
.destination-card:hover {
    transform: translateY(-10px);
}

.logo:hover {
    transform: scale(1.1) rotate(-5deg);
}

.order-card:hover {
    transform: translateX(10px);
}
```

**Переходы (Transitions):**
```css
/* Плавные переходы */
transition: all 0.3s ease;

/* Анимация подчеркивания ссылок */
.nav-menu a::after {
    transition: width 0.3s ease;
}

/* Transitions для форм при фокусе */
.form-group input:focus {
    transition: all 0.3s ease;
    border-color: #667eea;
    transform: translateY(-2px);
}
```

**Временные функции:**
- **ease** - плавное начало и конец
- **ease-in** - медленное начало
- **ease-out** - медленный конец
- **ease-in-out** - плавное начало и конец
- **cubic-bezier()** - пользовательские кривые

**Анимации (@keyframes):**

```css
/* 1. fadeIn - появление элементов */
@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
}

/* 2. slideInDown - спуск заголовков */
@keyframes slideInDown {
    from {
        transform: translateY(-50px);
        opacity: 0;
    }
    to {
        transform: translateY(0);
        opacity: 1;
    }
}

/* 3. slideInUp - подъем текста */
@keyframes slideInUp {
    from {
        transform: translateY(50px);
        opacity: 0;
    }
    to {
        transform: translateY(0);
        opacity: 1;
    }
}

/* 4. bounceIn - отскок формы поиска */
@keyframes bounceIn {
    0% {
        transform: scale(0.5);
        opacity: 0;
    }
    60% {
        transform: scale(1.05);
    }
    100% {
        transform: scale(1);
        opacity: 1;
    }
}

/* 5. pulse - пульсация элементов */
@keyframes pulse {
    0%, 100% { transform: scale(1); }
    50% { transform: scale(1.05); }
}

/* 6. float - плавающие иконки */
@keyframes float {
    0%, 100% { transform: translateY(0); }
    50% { transform: translateY(-20px); }
}
```

**Градиенты:**
```css
/* Linear gradients */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Hero секция */
background: linear-gradient(rgba(0,0,0,0.4), rgba(0,0,0,0.4));
```

**Тени (Box-shadow):**
```css
/* Базовая тень */
box-shadow: 0 5px 15px rgba(0,0,0,0.1);

/* При hover - увеличение тени */
box-shadow: 0 15px 30px rgba(0,0,0,0.2);

/* Цветные тени для кнопок */
box-shadow: 0 10px 25px rgba(102, 126, 234, 0.4);
```

**Другие техники:**
- **border-radius** - скругление углов
- **backdrop-filter: blur()** - размытие фона
- **Grid Layout** - для сеток (auto-fit, minmax)
- **Flexbox** - для гибких контейнеров
- **Псевдоэлементы** - ::before и ::after
- **Clip-path** - для создания нестандартных форм

### Адаптивная верстка

**Блочная и табличная модели:**
- **display: block** - основные секции
- **display: inline-block** - элементы навигации
- **display: flex** - гибкие контейнеры
- **display: grid** - сложные раскладки

**Flexbox примеры:**
```css
/* Центрирование */
display: flex;
align-items: center;
justify-content: center;

/* Распределение с gap */
display: flex;
gap: 2rem;
```

**Grid примеры:**
```css
/* Адаптивная сетка */
display: grid;
grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
gap: 2rem;

/* Двухколоночная */
grid-template-columns: 1fr 1fr;
```

**Медиа-запросы:**
```css
/* Планшеты */
@media (max-width: 968px) {
    .about-grid { 
        grid-template-columns: 1fr; 
    }
}

/* Мобильные устройства */
@media (max-width: 768px) {
    .burger { 
        display: flex; 
    }
    .nav-menu { 
        position: fixed;
        flex-direction: column;
    }
    .hero-content h1 { 
        font-size: 2rem; 
    }
}

/* Учет предпочтений пользователя */
@media (prefers-reduced-motion: reduce) {
    * { 
        animation: none !important; 
    }
}

/* Печать */
@media print {
    header, footer { 
        display: none; 
    }
}
```

**Адаптивные элементы:**
- Адаптивная навигация (бургер-меню)
- Гибкие сетки (Grid/Flexbox)
- Адаптивная типографика
- Responsive изображения

**Позиционирование элементов:**

1. **position: sticky**
   ```css
   header {
       position: sticky;
       top: 0;
       z-index: 1000;
   }
   ```

2. **position: relative/absolute**
   ```css
   .timeline-item {
       position: relative;
   }
   
   .timeline-item::before {
       position: absolute;
       left: 50%;
       transform: translateX(-50%);
   }
   ```

3. **position: fixed**
   ```css
   .nav-menu.active {
       position: fixed;
       top: 70px;
       left: 0;
       width: 100%;
   }
   ```

4. **Flexbox для выравнивания**
   ```css
   display: flex;
   justify-content: space-between;
   align-items: center;
   ```

5. **Grid для сложных раскладок**
   ```css
   display: grid;
   grid-template-columns: 1fr 1fr;
   gap: 3rem;
   ```
